# HSR 可玩版本交付

这是三张地图、既有功能 UI 和装备/遗器流程的可运行重做版本。功能修复和构建已有直接验证；美术精细度与首次玩家节奏不宣称全部达到参考标准。

## 启动与查看

- 本地 Windows Development：`Saved/Presentation/Package/Windows/HSR.exe`。
- 地图与 UI 截图索引：`Saved/Presentation/delivery.html`。
- 模型源文件：`ArtSource/Presentation/NightCityKit.blend`；15 个 FBX 同目录，图标源文件在 `ItemIcons/EquipmentIcons.blend`。
- 精确修改清单：`Saved/Presentation/change_manifest.json`；构建日志：`Saved/Presentation/package_final.log`。
- 完整验证过程：`docs/presentation-rebuild-execution.md`；性能记录：`Saved/Presentation/Performance/summary.json`。

启动后从观景列车枢纽开始。WASD 移动，鼠标调整视角，F 交互；Tab 打开旅途菜单，B 背包、T 队伍、M 地图。先与向导对话并调查观景厅记录，再通过月台旅行点或地图前往城区。城区有三个调查点、四个收集点、两组普通遭遇和一个精英遭遇。

## 主要改动

- 约 250×250 米六区城区、70×25 米枢纽和 65 米竞技场；建筑/道具实例化，保留稳定地图与交互身份。
- 背包分类、检索、物品图标、数量、强化等级和装备归属；明确装备角色，操作先预览再确认，取消不写状态。
- 武器与遗器更换/卸下，未装备遗器可强化，强化材料/等级限制与失败原因明确；重复确认不重复扣费。
- 编队与战前准备使用真实角色列表，支持撤销、换位、清空非队长位置；关闭或返回会恢复输入焦点。
- 战斗阵型/镜头、角色与目标头像、场景目标选择、稳定 SkillId、行动预测、治疗/伤害反馈和结算返回。
- 任务正式标题与目标说明、GAS 治疗终结技 100 能量成本及失败补偿、安全落脚点、任务存档恢复、已完成遭遇跨重启防重放。
- 修复部分队员死亡后战斗停滞、遗器页无关按钮堆叠、菜单小地图残影、结算残留战斗 HUD 及文字重叠。
