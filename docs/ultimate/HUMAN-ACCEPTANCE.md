# 终结技最终试玩验收（约 5–10 分钟）

状态：**HUMAN ACCEPTANCE PENDING**。以下路线由最终用户确认；Codex 图形自动输入、截图、构建和专项测试不能代替这个结果。

## 启动

双击项目中的 `tools/Ultimate/Play-Ultimate-Practice.cmd`。若本轮本地 Windows 包存在则优先打开；否则用已编译 UE Editor 的图形 Game 模式。入口使用现有 `Map_HertaSupportSection`、四人角色目录、生产 Coordinator/ASC/UI。仅显式开发参数 `-HSRUltimatePractice` 设置初始满能量和 70% HP，以便一次验证攻击与治疗；不写存档、不发持久奖励，Shipping 不开放该入口。

也可直接启动：

```powershell
& 'E:\work\unreal_projects\HSR\tools\Ultimate\launch_ultimate_practice.ps1' -Packaged
```

窗口为 1280×720。首次先点击一次战斗技能卡，让键盘焦点进入 HUD；也可始终用鼠标操作。下方四张终结技卡从左到右为长夜月、火花、蕾米埃尔、维琳娜；数字 1–4 对应这些卡。上方行动列表是普通行动预测，顺序与卡片排列不必相同。Q 选择普攻，E 选择战技，Enter 确认；也可以全程点击技能卡和右下角确认按钮。

## 试玩步骤

1. 初始普通行动者是火花。观察四人能量条和金色就绪卡；点击火花的终结技卡（2），点击敌人目标，再确认。看到实际角色动作、金色光效和镜头过渡后，确认顶部普通行动仍是火花。按 Q、Enter 继续普攻，应正常造成一次伤害。
2. 另一角色进入普通选择后，按 Q、Enter。其动作开始时立即按 1、Enter，随后按 4、Enter。应先完成原普通攻击，再按接受次序播放长夜月与维琳娜终结技。蓝色卡显示等待安全点及序号，不能同时播放两个释放镜头。
3. 第 2 步期间对已经等待/执行的同一卡连续确认数次。它应显示“此行动已经提交”或已在释放的反馈，不能再扣一次能量、再造成一次伤害。选另一名就绪队友仍应可以提交。
4. 观察第 2 步已确认的维琳娜终结技：目标显示“全队”，无须挑单人。每名存活队友 HP 应通过真实治疗变化；一次消耗 100 能量，成功恢复配置的 5 能量。若全员满血，该技能应明确不可释放。
5. 继续逐角色使用普攻，使敌方进入动作。预先准备鼠标/编号，在“巡检机”动作期间选择还就绪的蕾米埃尔（3）并确认。敌人当前伤害必须先落到队友，终结技随后才开始，不能吞掉敌方攻击。蕾米埃尔命令确认的是全体存活敌人。
6. 回到普通行动后继续 Q/Enter，确认行动列表、目标和确认按钮都能正常使用。随着普攻/战技、受击/击杀，能量应真实增长并裁剪到上限；未满时终结技卡显示不足。
7. 击败敌人，在结果界面点击确认。开发练习会进入新的 World 和全新战斗，不写持久奖励。确认四人初始能量重新准备，卡上没有旧等待序号或释放锁；再提交一次终结技和一次普攻。

若初次顺序操作与上述示例不同，使用尚未消费能量的角色即可。每个演出约 1.4 秒；可以先把鼠标放在目标卡上，再于敌方动作开始时确认。需要重来时可关闭练习窗口并重新双击启动入口。
